# Free pre-built 3D models for PC components

Research date: 2026-11-16. Scope: candidate free models for the 8 component kinds (cpu, gpu, board, ram, ssd, psu, cooler/AIO, case). No files were downloaded or committed.

## License rules

- **Allowed:** CC0 (best), CC-BY 4.0 / 3.0 (attribution required), MIT, Apache 2.0.
- **Not allowed:** CC-BY-NC, CC-BY-ND, editorial-only, "Free Standard" / "Royalty Free" / custom store licenses, and any unclear license.
- **Format:** a `.glb` or `.gltf` must be downloadable without login. `.blend`-only, `.fbx`-only or `.obj`-only files are rejected.

Verification notes: a listing marked UNVERIFIED was seen only in search snippets, or its page could not be fetched (403, 404 or empty content). Poly Pizza shows the license name without a version number, so the CC-BY version must be confirmed before use.
